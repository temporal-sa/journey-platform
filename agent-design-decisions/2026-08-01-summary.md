# Agent Design Decisions & System Architecture Summary (2026-08-01)

This document records all UX/UI design decisions, visual system architecture updates, backend orchestrator enhancements, OpenTelemetry tracing integrations, and E2E verification artifacts applied to the **Event-Driven Journey Platform** on **August 1, 2026**.

---

## 1. Inline Journey Name Editing & Header Integration (`web/src/App.tsx` & `editorStore.ts`)

- **Interactive Breadcrumb Component (`InlineJourneyName`)**:
  - Replaced the static journey name text in the top workspace header with `InlineJourneyName` (`Acme Corp / <InlineJourneyName />`).
  - Styled with Obsidian Dark glassmorphism principles:
    - **Default State**: Translucent periwinkle chip (`px-3 py-1 rounded-xl bg-[#c0c1ff]/10 hover:bg-[#c0c1ff]/20 text-[#c0c1ff] hover:text-white border border-[#c0c1ff]/30 hover:border-[#c0c1ff]/60 font-['Outfit'] font-bold text-sm transition-all shadow-sm backdrop-blur-md`).
    - **Editing Input State**: Obsidian surface container (`px-3 py-1 rounded-xl bg-[#11141d] border border-[#c0c1ff] focus:border-[#4cd7f6] focus:ring-2 focus:ring-[#4cd7f6]/30 text-white font-['Outfit'] font-bold text-sm outline-none transition-all shadow-inner`).
    - **Unsaved Changes Chip**: Amber uppercase badge (`UNSAVED`) displayed beside the name whenever `hasUnsavedChanges = true`.
- **Keyboard & Blur Semantics**:
  - Pressing **Enter**, **Tab**, or clicking outside (**onBlur**) commits the trimmed string to `editorStore` via `setDraftName`, pushes to the undo history stack, marks `hasUnsavedChanges = true`, and emits a live screen reader announcement (`useAnnouncer`).
  - Pressing **Escape** cancels editing and reverts to the prior draft name without saving.

## 2. ETag Concurrency & Mismatch Resolution (`client.ts`, `App.tsx`, `journey.go`)

- **Header Sanitization**:
  - Updated `buildHeaders` in `JourneyApiClient` (`client.ts`) to ignore `If-Match` when the value is `undefined`, `null`, `""`, or the literal string `'undefined'`, preventing false `412 Precondition Failed` / `409 Conflict` errors on un-persisted drafts.
- **ETag Persistence**:
  - Updated `handleSaveDraft` in `App.tsx` to capture the server-returned `ETag` header (`res.etag`) and update `currentDraft.content_hash` in `useEditorStore`.
- **Conflict Resolution Modal Wiring (`ConflictDialog.tsx`)**:
  - Wired `onKeepLocal` to issue a force-update request without `If-Match` headers, updating local store state and clearing unsaved flags.
  - Wired `onMerge` to compute node graph differences and post the merged draft state directly to the server.

## 5. Temporal Engine & Activity Worker Synchronization (`internal/workflows/`, `cmd/journey-worker`)

- **Task Queue Standardization**:
  - Aligned task queue constant `JOURNEY_TASK_QUEUE = "journey-engine-task-queue"` in `internal/workflows/workflows.go`.
- **Worker Connection Retry Loop (`cmd/journey-worker/main.go`)**:
  - Implemented a 30-attempt startup retry loop (2-second interval) to wait for Temporal server container readiness (`127.0.0.1:7233`).
- **Unified Activity Registration (`RegisterAllActivities`)**:
  - Created `RegisterAllActivities(r ActivityRegistrar, act *activities.Activities)` helper in `worker.go` to register all **14 engine activities** across worker bootstrapping and all unit test harnesses:
    - `ExecuteNode`, `EvaluateCondition`, `EmitOutcome`, `ExposeAssignment`, `LoadCompiledIR`, `EmitLifecycleEvent`, `ExecuteActionGateway`, `GetOrAssign`, `RecordExposure`, `CreateSubscription`, `CloseSubscription`, `EvaluatePolicy`, `ResolveAttributes`, `ResolveParameters`.
- **3-Tier IR Loading & Dynamic Fallback (`activities.go`)**:
  - Updated `LoadCompiledIR` with 3-tier lookup: In-memory cache `a.irStore` ➔ PostgreSQL database `a.repo.GetJourneyDraft` ➔ Dynamic synthetic IR fallback for client draft IDs.
- **Workflow Error Propagation**:
  - Updated all failure handlers in `CompiledJourneyWorkflow` (`journey_workflow.go`) to return non-nil errors (`return result, fmt.Errorf(...)`), causing Temporal Server to mark unrecoverable executions as **`FAILED`** with single attempt policy (`MaximumAttempts: 1`).
