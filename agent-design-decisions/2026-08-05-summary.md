## 4. Canvas Edge Handle Connection Resolution on Draft Reload

- **Handle Resolution ([`web/src/components/editor/Canvas.tsx`](file:///Users/khan/repos/puppeteer-condition-sms-nodes/web/src/components/editor/Canvas.tsx#L461-L481))**:
  Resolved an issue where reloading saved journey drafts caused True and False edges to visually attach to the same default handle (`id="true"`). Added dynamic `sourceHandle` fallback logic when converting GraphDraft edges to React Flow Edges:
  ```ts
  const resolvedSourceHandle =
    e.sourceHandle ||
    (e.condition === 'true' || e.id.includes('-true-')
      ? 'true'
      : e.condition === 'false' || e.id.includes('-false-')
      ? 'false'
      : e.condition || undefined);
  ```
  On draft reload, True edges connect to `id="true"` (left handle) and False edges connect to `id="false"` (right handle).
