# Agent Design Decisions & System Architecture Summary (2026-07-30)

This document records all UX/UI design decisions, visual system architecture updates, component refactorings, and interactive gesture fixes applied to the **Journey Control Engine** platform on **July 30, 2026**.

---

## 1. Design System & Palette Guidelines

- **Surface Strategy**:
  - Base Floor: `#0B0F19` (Obsidian Dark)
  - Card & Container Glass Panels: `#0F131D`/90 with backdrop blur (`backdrop-blur-xl`) and `#171b26` solid bases.
  - Borders: Subtle `#464554` (or 10%–30% opacity accent borders).
- **Typography & Font Families**:
  - Headings & Page Titles: `Outfit` (`font-['Outfit']`)
  - Body Copy & Labels: `Inter` / `Outfit`
  - Technical Specs, Event Names, Node IDs, Timestamps, Badges: `JetBrains Mono` (`font-mono`)
- **Interactive States**:
  - Hand Cursor: Enforced `.cursor-pointer !important;` across all interactive buttons, cards, selects, and icons.
  - Hover Brightness Glow: Standardized `.hover\:brightness-125:hover` filter on hover.

## 3. MiniMap Architecture (`web/src/components/editor/Canvas.tsx`)

1. **Bottom-Right Positioning**:
   - Anchored permanently at `bottom: 20px; right: 20px` via explicit CSS positioning (`.react-flow__panel.bottom.right`).
2. **Category Color-Coding**:
   - Triggers: Cyan (`#032b36` fill, `#4cd7f6` stroke)
   - Decisions: Amber (`#2a1c02` fill, `#f59e0b` stroke), Blue (`#071a38`), Purple (`#200738`)
   - Actions: Periwinkle (`#121330` fill, `#c0c1ff` stroke)
   - Utilities: Rose (`#36080b` fill, `#ffb4ab` stroke)
3. **Visual Edge Connections**:
   - Curved dual-layer bezier paths (`stroke="#6366f1"` glow + `#c0c1ff` dashed core line) connecting source nodes to target nodes across the MiniMap graph.
4. **Readable Mini Cards**:
   - Each mini-node card displays category geometry, icon circle, display name, and type badge (`TRIGGER`, `ACTION`, `CONDITION`, `DELAY`, `EXIT`).

## 4. Canvas Interactions & Gestures (`Canvas.tsx` & `editorStore.ts`)

- **60 FPS Node Dragging**:
  - Enabled smooth node dragging via `panOnDrag={true}` and `nodesDraggable={!isLocked}`.
  - Implemented `updateNodes(nodes, skipHistory)` with real-time position updates during active dragging (`dragging: true`), debouncing undo history entries until drag completion (`onNodeDragStop`).
- **Canvas Panning**:
  - Smooth panning when dragging empty canvas space (`.react-flow__pane`).
- **Box Selection & Multi-Node Selection**:
  - Enabled drag selection box via `selectionMode={SelectionMode.Partial}` and `selectionKeyCode="Shift"`.
  - Multi-selection state (`selectedNodeIds: string[]`) synchronized atomically across Zustand store.
- **Bulk Deletion**:
  - Pressing `Delete` / `Backspace` or clicking `Delete Selected` on the toolbar deletes all selected nodes and connected edges in a single atomic history step.

## 6. Information & Degraded State Alerts (`DegradedStateView.tsx`)

- Replaced light-mode inline styles (`#fef2f2`, `#fffbeb`) with Obsidian dark glassmorphic cards (`bg-[#0F131D]/90 backdrop-blur-xl border rounded-2xl p-6`).
- **Severity Color Mapping**:
  - Errors: `bg-rose-500/10 text-rose-200 border-rose-500/30` with `text-rose-300` headers.
  - Warnings: `bg-amber-500/10 text-amber-200 border-amber-500/30` with `text-amber-300` headers.
  - Info / Empty States: Translucent periwinkle `bg-[#c0c1ff]/10 text-[#dfe2f1] border-[#c0c1ff]/30` with `text-[#c0c1ff]` headers.
- **Action Buttons**: Styled with explicit dark base background (`bg-[#171b26]`) and matching severity borders (`border-rose-500/40`, `border-amber-500/40`, `border-[#ddb7ff]/40`), brightening on hover (`hover:brightness-125 hover:text-white cursor-pointer`).
- **Material Symbols Icons**: Replaced raw emojis with $40\text{px} \times 40\text{px}$ Material Symbols icon tiles.

## 7. Directories & Execution Pages (`JourneysPage.tsx` & `RunListPage.tsx`)

- **Status Badges**:
  - Unified corner rounding (`rounded` = $4\text{px}$) and typography (`px-2 py-0.5 rounded text-[10px] font-mono font-semibold uppercase border tracking-wider`) across directory and execution tables.
- **Interactive Status & Mode Filter Selectors**:
  - Replaced native `<select>` dropdowns with interactive color-coded status badge selector bars using `getStatusStyles` and `getModeStyles`.

- **Toolbar Height Alignment (`h-[34px]`)**:
  - Aligned Search inputs, Date pickers, Filter bars, and Clear Filters buttons to $34\text{px}$ height (`h-[34px]`) with bottom flex alignment (`flex flex-wrap items-end gap-4`).
