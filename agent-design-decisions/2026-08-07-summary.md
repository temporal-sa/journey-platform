# 2026-08-07 UX/UI Design & Architecture Decision Log

## Summary of Changes & Guidelines

### 1. Visual Execution Trace Graph Component (`ExecutionGraphView.tsx`)
- **ReactFlow Integration**: Created read-only execution trace visualizer supporting all 11 Journey Canvas node types (`EventStartNode`, `ConditionNode`, `EmailNode`, `SMSNode`, `PushNode`, `InAppNode`, `WebhookNode`, `DelayNode`, `WaitForEventNode`, `ExitNode`, `ExperimentNode`).
- **Trace Progress Overlays**:
  - **Visited / Completed Nodes**: Glowing emerald green borders (`#34d399`), shadow highlights (`shadow-[0_0_15px_rgba(52,211,153,0.4)]`), and step sequence badges (`Step 1`, `Step 2`).
  - **Active / Paused Node**: Pulsing cyan border (`#4cd7f6 animate-pulse`) showing where the execution is paused (e.g. waiting at `WaitForEvent` or `Delay`).
  - **Unvisited Branch Nodes**: Muted opacity (`opacity-45`) to visually distinguish executed paths from unvisited branches.
- **Traversed Connections**: Rendered as static non-animated cyan Bezier paths (`#4cd7f6`, `strokeWidth: 2.5`, `animated: false`).

### 2. Event-Sourced Projections & Node ID Normalization
- **Database Projection**: Integrated PostgreSQL `lifecycle_events` read model (`ListLifecycleEventsByEntity`) so visual trace status is derived directly from recorded execution events without polling Temporal gRPC.
- **IR Node ID Prefix Normalization**: Added `replace(/^ir-/, '')` to `findMatchingStep` in `ExecutionGraphView.tsx` so engine-emitted node IDs (`ir-node-start`, `ir-node-cond`, `ir-node-wfe`) match canvas draft node IDs (`node-start`, `node-cond`, `node-wfe`) with 100% precision.

### 3. Shared Canvas & Execution MiniMap Component (`CustomMiniMapNode.tsx`)
- **Shared Component Extraction**: Created `web/src/components/editor/CustomMiniMapNode.tsx` consumed identically by both `Canvas.tsx` (Journey Canvas Editor) and `ExecutionGraphView.tsx` (Visual Trace Graph).
- **Sharp Rectangular Geometry**: Enforced 0px sharp rectangular node shapes (`rx={0}`, `ry={0}`) across all MiniMap node types matching actual Journey Canvas node components.
- **Real-Time SVG Connections & Navigation**: Draws Bezier edge curves directly on the MiniMap canvas with active cyan path highlights and interactive drag-panning (`pannable={true}`, `zoomable={true}`).

### 4. Bidirectional Shareable URL Hash Routing (`useRouteParams.ts` & `App.tsx`)
- **Shareable Hash URLs**: Supported query parameters (`/#/run-detail?runId=...&subRunId=...`) and path segments (`/#/run-detail/RUN_ID/SUB_RUN_ID`) via `parseHashRoute()`.
- **Live Address Bar Sync**: Selecting sub-run contact traces dynamically updates the browser address bar in real-time via `window.history.replaceState` without page reloads.

### 5. Sub-runs Directory Table Refinements (`RunDetailPage.tsx`)
- **Solid Active Row Background**: Active sub-run table row applies a solid obsidian cyan-navy background (`#043d4d`), a solid cyan left border accent line (`border-l-4 border-l-[#4cd7f6]`), and inset box-shadow dimension locking (`boxShadow: inset 4px 0 0 #4cd7f6`).
- **Action Column Button Alignment**:
  - **Active Trace Row**: Displays a disabled, dimmed `Inspect Trace` button (`variant="secondary-dark"`, `disabled={true}`, `opacity-50 cursor-not-allowed`) alongside active action buttons.
  - **Inactive Rows**: Displays standard purple `Inspect Trace` button (`variant="secondary-dark"`, `size="sm"`, `icon="visibility"`, `bg-[#b76dff]/20 text-[#ddb7ff] border-[#ddb7ff]/30 font-semibold`) matching all directory tables.
  - **Temporal History Button**: Displays `Temporal History` button (`variant="secondary-dark"`, `size="sm"`, `icon="schedule"`) opening live Temporal Web UI workflow history (`http://localhost:8233/...`) in a new tab.
  - **Per-Subrun Signal Button**: Displays `Signal` button (`variant="secondary-dark"`, `size="sm"`, `icon="sensors"`, `bg-[#4cd7f6]/20 text-[#4cd7f6] border-[#4cd7f6]/30 font-semibold`) pre-populating target sub-run workflow ID (`wf-${workflow_id}-${sub_run_id}`) and customer ID.
- **Header Cleanup**: Re-titled section header to **`Sub-runs`**, removed contacts badge and divider line, and rendered page header Run ID as clean unbordered monospace text (`text-[#4cd7f6] font-mono text-base font-semibold`).

### 6. Signal Simulation Modal & Toast Notifications (`SignalSimulationModal.tsx`)
- **Modal Component**: Formatted using standard `<Modal>` component with `sensors` icon, `#0F131D` obsidian glass surface, `#464554` slate borders, and `font-['Outfit',sans-serif]` UI display typography (retaining `font-mono` exclusively on the JSON payload textarea).
- **Dynamic Preset Payload Mapping**: Clicking quick signal presets (`Order Completed`, `User Converted`, `Email Opened`, `Email Clicked`, `Cart Abandoned`) automatically updates `payloadJson` to match the target event schema.
- **Toast Notifications & Auto-Close**: Replaced inline text banners with top-center Toast notifications (`ToastMessageType.SUCCESS` / `ToastMessageType.ERROR`) and auto-closes the modal upon successful event emission.

### 7. Obsidian Design System Skill Updated (`skill://obsidian-design-system`)
- Added **Section 8: Dark Mode Toggle & Preset Button Rules (Mandatory)** to `.agents/skills/obsidian-design-system/SKILL.md`.
- Prohibits light mode button fills (`#ffffff`, `bg-white`, `bg-gray-100`) and documents exact dark mode active tokens (`bg-[#4cd7f6]/20 text-[#4cd7f6] border-[#4cd7f6]/60`) and inactive tokens (`bg-[#171b26] text-[#908fa0] border-[#464554]/60`).
