# 2026-08-07 UX/UI Design & Architecture Decision Log

## Summary of Changes & Guidelines

### 1. Dark Mode Active Toggle & Preset Button Standards
- **Mandatory Zero Light Mode Exception**: Strict enforcement across the entire application preventing solid white, light grey, or unstyled light mode button fills (`#ffffff`, `bg-white`, `bg-slate-100`, `bg-gray-200`) on active toggle states or preset chips.
- **Active State Token Standard**:
  - **Cyan Active Preset**: `bg-[#4cd7f6]/20 text-[#4cd7f6] border border-[#4cd7f6]/60 font-bold shadow-sm`
  - **Lavender / Action Active Preset**: `bg-[#c0c1ff]/20 text-[#c0c1ff] border border-[#c0c1ff]/60 font-bold shadow-sm`
  - **Emerald Active Preset**: `bg-emerald-500/20 text-emerald-300 border border-emerald-500/60 font-bold shadow-sm`
  - **Amber Active Preset**: `bg-[#f59e0b]/20 text-[#f59e0b] border border-[#f59e0b]/60 font-bold shadow-sm`
- **Inactive State Token Standard**: `bg-[#171b26] text-[#908fa0] border border-[#464554]/60 hover:text-white hover:border-[#dfe2f1]/40`
- **Design Skill Updated**: Documented in `skill://obsidian-design-system` under Section 8.

### 2. Signal & Ingress Event Simulation Modal (`SignalSimulationModal.tsx`)
- Integrated signal simulation modal launched via top bar action icon (`rss_feed`) on `RunDetailPage.tsx`.
- Formatted matching all Obsidian dark theme modal guidelines (`font-['Outfit']`, `#0F131D` obsidian glass surface, `#464554` slate borders, `font-mono` tokens, and `<Button>` components).

### 3. Shareable Hash URL Routing & Subrun Directory Table Refinements
- **Bidirectional Hash Routing**: Shareable URL links (`/#/run-detail?runId=...&subRunId=...`) dynamically parse and synchronize run & sub-run IDs in real time via `parseHashRoute()`.
- **Solid Active Row Background**: Active sub-run row applies a distinct solid obsidian navy background (`#043d4d`) with a cyan left border line (`border-l-4 border-l-[#4cd7f6]`).
- **Button Removal & Unified Inspect Button**: Removed button component from active row, and unified `Inspect Trace` on inactive rows to use `<Button variant="secondary-dark" size="sm" icon="visibility">` matching all directory tables.
